# 项目文档

这里存放 `9field.org` 的详细背景与长期决策。文档中的状态使用：**事实**、**建议**、**待确认**。

- [`asset-map.md`](asset-map.md)：现有数字资产、建议归属和迁移边界。
- [`frontend.md`](frontend.md)：前端产品边界、视觉系统与技术架构。
- [`deployment.md`](deployment.md)：Cloudflare 项目、环境、域名与发布流程。
- `decisions/`：影响长期架构或资产归属的决策记录（出现首个决策时建立）。

文档不得记录密码、令牌、Cloudflare API Token、账户 ID 或其他敏感信息。
