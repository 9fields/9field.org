# 前端方案

状态：**已实施**

更新日期：2026-08-12

## 产品边界

`9field.org` 是九野的品牌、产品、技术与社区门户，不是公司正式主站。企业介绍、主体资质、商务联系和合规信息统一指向 `9fields.cn`。

首版只呈现已经确认的内容：品牌叙事、关注方向、双站关系及两个 GitHub 组织入口。没有真实资料支撑的产品、案例、新闻、成员或统计信息不在页面中展示。

## 技术架构

- Astro 5，严格 TypeScript，构建结果为纯静态 HTML、CSS 与少量导航脚本。
- 页面区段拆分为组件；站点文案与链接集中在 `src/data/site.ts`。
- 不使用数据库、CMS、登录、表单提交、API 或 Cloudflare Worker 运行时代码。
- 字体使用系统中文字体栈，不依赖第三方字体服务；等高线视觉为内联 SVG。
- 当前路由包括首页和静态 404 页面。

## 视觉系统

- 深墨蓝代表技术与空间感，玉绿色用于路径和行动提示，白色内容区负责长文本可读性。
- 中文标题采用宋体风格，正文与控件采用黑体风格。
- 主要视觉母题为“九片原野”的等高线，保持抽象，不暗示尚未存在的具体产品。
- 桌面采用开放式横向编排；移动端转为单列，并提供可键盘操作的导航菜单。

## 何时需要后端

只有出现明确的服务端需求时才新增后端，例如内容编辑工作流、邮件订阅、账号系统、搜索索引或实时数据。届时应先记录架构决策，再选择 Cloudflare Workers、D1、R2 或外部服务；不得为了“以后可能需要”提前引入。
